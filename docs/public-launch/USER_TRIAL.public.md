# ZZ Board {{VERSION}} / {{CHANNEL}} 公测

让 Agent 在你的源码项目里按[部署指南](DEPLOYMENT_QUICKSTART.md)构建 Windows 桌面。打开它交付的长期入口。下次做 Skin、更新或排错，都回到这个项目。

## 三分钟试一张便签

1. 双击画布空白处，写「明天试一下」，选好中文候选字后点空白。
2. 把鼠标停在文字上，看编辑时间。单击便签，在原位置附近把文字改成「明天试一下新的背景图」。
3. 点「安排」，选明天为「预期完成日期」，勾选「按日期自动提升」，再点「保存安排」。收起便签，看看有没有出现「优先」。
4. 从右下角托盘选择「真正退出」，点刚才固定的任务栏图标。找回那句话，再看日期还在不在。

遇到问题时记一句「第几步、点了什么、实际看到什么」就够了。

## 想继续试试

1. 按 N 写下一条便签，结束编辑、移动、连线、绘制；退出重开应保留。中文输入后立刻点击空白，再看最后几字、标点和空行。
2. 粘贴不含隐私的测试图片；用区域 PNG 导出，检查本机保存结果和外部应用粘贴，区分保存与剪贴板各自的成功/失败。
3. 归档再恢复一张便签；连接、位置和优先级保留。永久删除需要单独确认，不能为了排错清空数据库或恢复草稿。
4. 若你使用 Codex，从「项目 → 项目更新 → 来源授权」分别允许本地读取和模型整理，再点「准备并检查 Codex」核对登录与模型目录。在「项目更新」复制同步指令，交给 Codex Desktop，并指定希望读取的项目。已有项目也能在概览查看最近三条本机对话。实际整理会使用当前登录额度，采集与独立总结的用量分开记录。

想要不同形状的便签、背景和配色，可以把 [Agent 指南](USER_AGENT_GUIDE.md) 和[定制入口](AGENT_CUSTOMIZATION.md)交给自己的 Agent。Skin 支持声明式外观参数，新交互可从对应版本源码扩展。「数据与帮助 → 使用指南」提供操作说明，本仓库的手册和制作 Skill 可直接交给 Agent。

可以再新建一页，把项目气泡及明确收纳的便签一起移过去，撤销／重做并退出重开；核对位置、正文、图片和跨页关联。页面归档后只读，恢复后自动检查仍暂停，需要手动继续；移到别页则遵循目标页检查状态。触屏、触控笔、不同 Skin 与中文输入属于实际设备检查；源码测试不能保证设备手感。重要资料先备份，图片与数据库一起保存。

## 反馈

打开「反馈与帮助」，选择问题或建议。写下你想做什么、实际发生什么、预期怎样。预览要公开的文字，移除私人信息，然后复制或保存。在源码正式发布、GitHub Issues 开通后，进入对应表单，自己粘贴、确认并发布。公开的报告会署上你的 GitHub 身份。安全问题请遵循 [SECURITY.md](../SECURITY.md)。[报告问题](https://github.com/zh3zhou/zz-board/issues/new?template=bug.yml) · [提出建议](https://github.com/zh3zhou/zz-board/issues/new?template=feature.yml)

最有用的记录是版本、操作、预期、实际、是否能再次出现，以及你继续使用或放弃的原因。没有被邀请执行整份任务卡也可以反馈；不要求注册 GitHub 或给项目点赞。

## 更新与回退

更新前先保存便签，从托盘选择「真正退出」，备份当前看板。让 Agent 核对当前安装和源码中的个人改动，在原位置更新。回退程序时使用匹配的旧版本和升级前完整备份。
