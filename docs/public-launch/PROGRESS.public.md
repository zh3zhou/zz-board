# Public progress

## {{RELEASE_DATE}} · {{VERSION}} / {{CHANNEL}} 源码预览

这是经过审核的 Windows x64 源码预览。源码通过自动检查、标准桌面构建与运行文件校验。当前候选的原生首用、中文输入与系统剪贴板、托盘退出重开和升级恢复仍待实测。

- 决定：用户在 Codex 等本地编程 Agent 中打开完整源码，由 Agent 构建并管理 Windows x64 桌面；免费社区修改与对应源码分发采用李哲舟（Li Zhezhou）确认的 Source Available 1.0 许可，见 LICENSE。首发面向 Windows 桌面，新建看板默认使用「夜墨 3.0」。
- 首测反馈在本机预览、复制或保存，随源码预览开放 GitHub 的问题与建议表单。CloudBase 私有反馈的实现、证据及继续联调的条件保存在[技术归档](cloudbase/feedback/CLOUD_FEEDBACK_ARCHIVE.md)。
- 首次使用：交互快速开始、三条任务型说明、显式 Codex 读取/模型同意，以及可直接交给 Agent 的完整指南；制作 Skin、修改源码和后续维护都回到同一个源码项目。准备检查与总结运行时安全探测分别报告。
- 复核修正：授权撤销后阻止等待中的后续 RPC/文件读取；独立总结退出后释放自身管道。登录身份/模型目录、真实模型请求、当前额度与安全检查各自需要对应证据。
- CloudBase 技术归档保留临时函数的部署与删除实验记录。源码预览的反馈渠道为 GitHub Issues。
- 发布门禁：源码/版本校验、合成回归、干净源码构建、实际分发的源码及第三方材料、首次启动和合成截图。实际结果必须在运行后追加，不从旧本机 PASS 推导。
- 此前的源码首发演练已在隔离的 Windows 用户配置中从源码构建 0.11.0。新 Agent 找到了正在运行的原生窗口、固定入口、数据与源码位置，并从仓库生成了可预览的夜读 Skin。旧版画布用实际中文候选选字并粘贴 Windows 剪贴板图片，原址更新后图文仍可见。触屏、触控笔及各 Skin 在具体设备上的手感需实机体验。

后续贡献继续在此记录有公共证据的决定、结果、剩余事项和 superseding 记录，不复制私人对话或旧本机路径。
