# Windows 触控笔人工验收

本清单只用于有物理触控笔的 Windows + WebView2 环境。自动测试已经覆盖数据格式和压力降级，但不能证明某一支笔、驱动与屏幕组合的手感。

1. 用正式 `ZZ Board.exe` 打开合成或空白测试数据，不使用真实任务内容。
2. 分别用鼠标和笔画慢线、快线、点、闭合圈；确认线条连续，光标离开窗口后不会继续画。
3. 逐渐增加笔压，确认画笔宽度平滑变化；悬空移动不落墨，笔尾没有突然变粗。
4. 在 0.2、0.5、1、2.2 倍缩放重复绘制；确认落点与指针对齐，刷新后坐标不漂移。
5. 切换荧光笔、整笔橡皮、精细橡皮和套索；确认一次手势只形成一步撤销。
6. 按住 `Space` 用笔或鼠标平移，松开后回到原工具；编辑便签时快捷键不得抢占输入。
7. 画 1000 条短笔迹并同时显示 67 个合成节点；极远景不闪烁，拖动、缩放与选择没有明显掉帧。
8. 开启 Windows“减少动画”，重新打开应用；确认 Skin 动效和漂浮动画停止，但绘制与选择仍正常。

记录设备、Windows 版本、WebView2 版本、笔型号和失败步骤。发现坐标错位或断笔时，不要用真实数据继续测试。
